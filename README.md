# 光遇每日任务

查看《光·遇》国服的每日任务、季节蜡烛、天气、日历和公告，支持查看最近 30 天的历史记录。

[打开网页](https://skydaily.nankki.com/) · [下载安卓客户端](https://skydaily.nankki.com/app/)

## 使用方式

- **网页**：在浏览器中查看任务与攻略，勾选完成进度，按日期查阅历史内容。
- **安卓客户端**：支持 Android 9 及以上版本，提供任务与资讯查看、悬浮面板、饭点提醒和离线缓存。
