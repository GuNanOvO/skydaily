# 安卓客户端使用指南

[下载 App](https://skydaily.nankki.com/app/) · [App 简介](../app/README.md) · [网页使用指南](website.md)

客户端用于查看《光·遇》国服任务、攻略、季节蜡烛、天气、日历和公告，支持 Android 9 及以上版本。首次使用或查看尚未加载的内容时需要联网。

## 安装与更新

1. 在浏览器中打开下载页，查看版本和系统要求。
2. 点击「下载 APK」，下载完成后打开安装包。
3. 首次安装时，按系统提示允许当前浏览器或文件管理器安装应用，再继续安装。

安装完成后，可以关闭该浏览器或文件管理器的安装授权。

更新时，在「记录 → 设置 → 关于」点击「检查更新」，按提示下载并安装。覆盖安装会保留已有设置与任务进度，下载过程中可以取消。卸载后再安装不等同于覆盖更新。

## 页面入口

| 入口 | 可以做什么 |
| --- | --- |
| 今日 | 查看每日任务、攻略和季节蜡烛指南，记录任务完成进度 |
| 资讯 | 查看饭点状态、天气、日历和公告，进入提醒设置 |
| 记录 | 选择历史日期，打开设置，控制悬浮球 |
| 记录 → 设置 | 调整主题、悬浮球、饭点提醒和缓存，查看版本并检查更新 |

有图文的任务可以点开查看；大图支持双指缩放、双击放大和拖动。

## 任务进度

只有当天任务可以勾选，历史任务只读。日期按北京时间计算，进入新的一天后使用当天的进度。

进度保存在当前设备中，与网页、其他设备的记录分别保存，不会互相同步。

## 悬浮球

悬浮球可在使用其他应用时打开任务面板。

1. 打开「记录 → 设置 → 悬浮窗」，按提示允许「显示在其他应用上层」。
2. 返回 App，点击「显示」。
3. 点按悬浮球查看任务；拖动后松手，悬浮球会吸附到屏幕边缘。
4. 点击任务面板外或面板上的「关闭」，可收起面板。需要停用悬浮球时，在悬浮窗设置中点击「关闭」。

### 仅在游戏内显示

此选项从 0.2.0 起提供，默认关闭。

点击整行切换，右侧「已开启／已关闭」表示当前设置。

支持网易官方版及华为、vivo、哔哩哔哩、九游／阿里、应用宝渠道客户端。识别依据是游戏客户端，不是手机品牌。

开启「仅在游戏内显示」后，按提示允许「使用情况访问权限」，用于判断光遇国服是否处于前台。未授权时，悬浮球会保持隐藏。

- 光遇国服处于前台时显示悬浮球。
- 切到桌面或其他应用时，悬浮球和已展开的任务面板一起隐藏。
- 返回游戏后恢复悬浮球；锁屏时保持隐藏。
- 关闭此选项后，恢复在其他应用上方显示。

应用切换后，显示状态可能有短暂延迟。自动隐藏不会停用悬浮球；需要完全关闭时，仍应使用悬浮窗设置中的「关闭」。

## 饭点提醒

饭点按北京时间计算：08:00、10:00、12:00、16:00、18:00、20:00、22:00，每次持续 30 分钟。

在「设置 → 饭点提醒」选择需要提醒的时段，再打开提醒开关。可以调整提前提醒的分钟数，修改后点击「保存」。取消某个时段或关闭提醒开关后，对应提醒会取消。

按界面提示允许通知和精确提醒。App 不必一直停留在前台；如果手机限制后台运行，还需在系统设置中允许自启动与后台运行。强制停止 App 后，需要手动打开一次恢复提醒。

## 系统授权

按需要使用的功能开启相应授权即可。

| 功能 | 需要的授权 | 作用 |
| --- | --- | --- |
| 显示悬浮球 | 显示在其他应用上层 | 在其他应用上方显示悬浮球与任务面板 |
| 仅在游戏内显示 | 使用情况访问权限 | 判断光遇国服是否处于前台 |
| 饭点通知 | 通知 | 显示提醒通知 |
| 按设定时间提醒 | 闹钟和提醒；部分界面显示为精确提醒 | 允许系统按设定时间安排提醒 |

普通任务查看不需要开启悬浮球相关授权。不使用「仅在游戏内显示」时，也不需要使用情况访问权限。

## 主题与缓存

在「记录 → 设置 → 外观」选择浅色、深色或自动主题。自动模式在北京时间 19:00–07:00 使用深色，手动选择优先。

已加载的内容可以在缓存保留期间离线查看；未加载的图片、指南和历史日期仍可能需要联网。如果内容持续显示异常，可以联网后到「设置 → 缓存」点击「清除并重新获取」。

## 常见问题

### 悬浮球没有出现

先检查是否已点击「显示」，以及系统是否允许显示在其他应用上层。若开启了「仅在游戏内显示」，还需确认使用情况访问权限已允许，并切回光遇国服。

### 饭点没有提醒

检查所选时段、提醒开关、通知与精确提醒授权，再检查手机是否限制了 App 的后台运行。被强制停止后，先手动打开一次 App。

### 任务日期较早，或部分内容无法加载

确认网络后刷新，并查看内容的日期与更新时间。离线时可能显示上次加载的内容，未加载的图片与指南也可能暂时不可用。

### 如何反馈问题

在「设置 → 关于」确认应用版本后，通过 [仓库 Issues](https://github.com/GuNanOvO/skydaily/issues) 提供应用版本、手机型号、系统版本和操作步骤。若涉及悬浮球，请注明光遇的下载渠道；界面异常可附截图。
