# 光遇每日任务 · 安卓客户端

查看《光·遇》国服的每日任务、攻略、季节蜡烛、天气、日历和公告。支持 Android 9 及以上版本。

[下载 App](https://skydaily.nankki.com/app/) · [完整使用指南](../docs/app.md) · [网页版](https://skydaily.nankki.com/)

## 开始使用

1. 打开下载页，点击「下载 APK」。
2. 下载完成后打开安装包，按系统提示完成安装；首次安装时可能需要允许当前浏览器或文件管理器安装应用。
3. 打开 App，联网加载内容后即可查看任务。

## 常用入口

- **今日**：查看任务、攻略和季节蜡烛指南，记录当天的完成进度；在刷新按钮旁开启或关闭悬浮窗。
- **资讯**：查看饭点状态、天气、日历和公告，进入饭点提醒设置。
- **记录**：查看历史日期、打开设置，或开启悬浮球。历史任务只读。

任务进度保存在当前设备，按北京时间区分日期，与网页及其他设备分别记录。

## 设置与授权

设置入口位于「记录 → 设置」。可调整主题、悬浮球、饭点提醒、今日数据自动刷新与镜像来源。

- [悬浮球](../docs/app.md#悬浮球)：打开任务与资讯面板，调整位置和显示范围。
- [饭点提醒](../docs/app.md#饭点提醒)：选择时段和提前提醒时间。
- [系统授权](../docs/app.md#系统授权)：按所用功能开启相应权限。
- [主题与缓存](../docs/app.md#主题与缓存)：选择明暗主题，设置每日自动刷新与 jsDelivr／ghfast.top 镜像，处理离线内容与缓存。

今日数据从 CF API、Pages 和一个所选镜像中自动择路。自动刷新默认开启：进程运行期间跨天获取，失败每 10 分钟重试，当天成功后停止自动请求；手动刷新始终可用。

「允许使用移动或计费网络」为附属开关，默认关闭；关闭时不在移动或计费网络下自动获取今日数据，手动刷新不受限制。

## 应用更新

在「记录 → 设置 → 关于」点击「检查更新」，按提示下载并安装。覆盖安装会保留已有设置与任务进度。
